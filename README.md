# Mutun Memorizer Bot

Telegram-бот для постепенного заучивания коротких матнов. Пользователь выбирает книгу и темп, а бот каждый день отправляет страницу матна картинкой и аудио к ней.

Что умеет бот:

- ежедневные задания по выбранному времени;
- личный кабинет Telegram Mini App по адресу `/app`;
- максимум 2 активные книги одновременно, чтобы пользователь не путался;
- явная кнопка `Следующая страница`, если нужно продолжить сразу;
- темп 1, 2 или 3 страницы в день;
- режимы: текст и аудио, только текст, только аудио, только повторение;
- кнопки после задания: `Выучил`, `Сложно`, `Повторить завтра`;
- повторения после выученного: завтра, через 3 дня, через неделю и через 2 недели;
- самопроверка: сначала прочитать по памяти, потом открыть текст;
- прогресс по всем выбранным книгам;
- пауза на 1 день, 3 дня или без срока.

## Старт

```bash
cp .env.example .env
npm install
npm run content:fetch
npm run content:prepare
npm run dev
```

В `.env` нужен `BOT_TOKEN` от BotFather.

## Личный кабинет

Кабинет открывается из Telegram через команду `/app` или нижнюю кнопку меню `Кабинет`.

Внутри есть:

- `Сегодня` - главный план дня, новые страницы, повторения и кнопка начала занятия;
- `Учеба` - пошаговое занятие: прочитать, послушать, повторить, отметить результат;
- `Книги` - книги в занятиях, книги вне занятий и каталог;
- `Читать` - полный текст книги по страницам с аудио;
- `Повтор` - повторения и слабые страницы;
- `Прогресс` - цель недели, календарь привычки, история и прогноз по книгам.

Интерфейс сделан в нейтральном графитовом стиле без ярких зелёных акцентов. Основной акцент - спокойный серо-золотой.

У каждой книги есть кнопка `Читать полный текст`: она открывает все подготовленные страницы книги в режиме чтения с переходом назад/вперёд и аудио к странице.

API кабинета лежит под `/api/app/*` и проверяет Telegram Web App `initData`, поэтому прогресс привязан к Telegram-пользователю.

После каждого задания бот сохраняет события занятий в `state.json`: выдачу страниц, отметку результата, изменения недельной цели. На этих событиях строятся история по дням, календарь привычки и слабые страницы.

Если у пользователя есть активные книги и за день нет отметки результата, планировщик после `20:00` отправляет одно Telegram-напоминание: `Сегодня еще не занимался`.

## Контент

Источники лежат в `content/sources.json`. Сейчас добавлены:

- `Три основы / ثلاثة الأصول`
- `Четыре правила / القواعد الأربع`
- `Кашф аш-шубухат / كشف الشبهات`
- `Навакид аль-Ислам / نواقض الإسلام`
- `Шесть основ / الأصول الستة`
- `Китаб ат-таухид / كتاب التوحيد`
- `Сорок хадисов ан-Навави / الأربعون النووية`
- `Тухфат аль-атфаль / تحفة الأطفال`
- `Аль-Байкуния / البيقونية`
- `Аль-Аджуррумия / المقدمة الآجرومية`
- `Аль-Акыда аль-Васития / العقيدة الواسطية`
- `Масаиль аль-джахилийя / مسائل الجاهلية`

`npm run content:fetch` скачивает PDF и MP3 в `content/raw`.

`npm run content:prepare` рендерит PDF-страницы в PNG и делит MP3 на равные фрагменты по числу страниц. Это MVP-нарезка: для точного соответствия матна аудио позже лучше заменить равномерное деление на ручные таймкоды или распознавание/разметку.

Планировщик запускается каждый час (`DELIVERY_CRON=0 * * * *`) и отправляет задания тем пользователям, у которых выбран этот час. Так работает команда `/time`.

## Команды бота

- `/start` или `/books` - выбрать книгу
- `/app` - открыть личный кабинет
- `/today` - получить сегодняшнее задание сразу
- `/next` - получить следующую страницу сразу
- `/progress` - посмотреть прогресс по книгам
- `/time` - выбрать время ежедневного задания
- `/mode` - выбрать режим: текст и аудио, только текст, только аудио, только повторение
- `/check` - проверить себя по последнему заданию
- `/pause` - поставить занятия на паузу или продолжить

## Расписание

По умолчанию отправка идёт каждый день в `08:00` по `Asia/Bishkek`.

Настройки:

```env
APP_TIMEZONE=Asia/Bishkek
DELIVERY_CRON=0 8 * * *
```

## Права на материалы

Код не хранит скачанные PDF/MP3 в git. Перед публичным запуском нужно проверить разрешения на распространение выбранных изданий и начиток. В `content/sources.json` у каждого материала оставлены ссылки на страницу-источник и примечание.
